# AI Assisted Coding Rounds

> [!abstract] What this is
> Coding interviews where you are **given or allowed an AI assistant** (CoderPad's AI Assist, Copilot, Cursor, Claude, Gemini) and graded on how well you work with it: decomposing the problem, prompting in small checkable steps, verifying everything it writes, and explaining code you didn't type. Researched November 2026. Not the same as the AI-engineer rounds about building LLM systems, which are in [[AI Engineer Round Drills]].

## The One-Paragraph Version

- The AI can write code quickly, so the round scores **everything around the code**: understanding the problem, choosing the approach yourself, giving the model narrow tasks, catching its mistakes, testing, and owning the result.
- The two classic ways to fail: **hands-off** (pasting the whole problem in and accepting the answer) and **hands-on to a fault** (ignoring the assistant and typing everything yourself; one candidate rejected by Meta in 2026 was told by the recruiter to do "less manual work, more on AI").
- Most interviews still **ban** AI. A vendor survey of 400 engineering leaders in the US, India and China (January 2026) found 62% of organisations prohibited it in technical interviews. Ask the recruiter for the rules of **every** round, in writing.

## Before Any Loop: What to Ask the Recruiter

- Is any round in my loop AI-assisted? Which one?
- For the other rounds: are AI tools, autocomplete or running code allowed?
- Which editor or platform? Is there a practice environment?
- If an assistant is provided: which models, and can it edit files or only chat?
- Any in-person round? Whiteboard or laptop?
- For take-homes: what's the AI policy?

Keep the reply. Using an assistant where it's forbidden is misrepresentation and companies that publish a rule (Amazon's reported guidelines, Datadog's public ones) name disqualification as the penalty.
